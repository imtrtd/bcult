# I/TD Neon Spiral — приложение для Windows

Десктопная версия превью `imtrtd_neon_max_preview_v4.html`: тот же движок спирали
(колесо / перетаскивание / стрелки), без браузера, с собственным окном, иконкой и
ярлыком на рабочем столе.

## Что внутри

```
desktop/
├─ main.js                 процесс окна: рамка, полноэкранный режим, память размера окна
├─ preload.js              безопасный мост между окном и интерфейсом
├─ renderer/
│  ├─ index.html           разметка и стили — 1:1 с оригиналом
│  ├─ spiral.js            движок спирали (логика оригинала без изменений)
│  ├─ projects.js          ← список проектов, редактируется вручную
│  ├─ app.css              неоновый заголовок окна и кнопки
│  └─ app.js               кнопки окна, F11, внешние ссылки
├─ scripts/make-icons.js   генератор иконки (build/icon.ico, все размеры)
└─ build/icon.ico          иконка приложения / ярлыка / установщика
```

## Сборка .exe (на компьютере с Windows)

Нужен [Node.js 20+](https://nodejs.org). В PowerShell:

```powershell
cd desktop
npm install
npm run dist
```

В папке `desktop/dist` появятся два файла:

| Файл | Что это |
|---|---|
| `I-TD Neon Spiral-1.0.0-x64.exe` | установщик: ставит приложение, создаёт **ярлык на рабочем столе** и пункт в меню «Пуск» |
| `I-TD Neon Spiral-1.0.0-portable.exe` | портативная версия: один файл, запускается без установки (можно положить прямо на рабочий стол) |

Сборка не подписана сертификатом, поэтому при первом запуске Windows SmartScreen
покажет предупреждение → «Подробнее» → «Выполнить в любом случае».

### Сборка без Windows под рукой

В репозитории есть workflow `.github/workflows/desktop-windows.yml`. Запустите его
на вкладке **Actions → Build Windows app → Run workflow** — GitHub соберёт оба
`.exe` на своей Windows-машине и приложит их к запуску как артефакт
`itd-neon-spiral-windows`.

## Запуск без сборки (проверить приложение)

```powershell
cd desktop
npm install
npm start
```

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Листать спираль | колесо мыши, перетаскивание, ↑ ↓ ← → , PageUp / PageDown |
| В начало / в конец | Home / End |
| Открыть проект | клик по карточке |
| Полный экран | F11 (выход — F11 или Esc) |
| Масштаб | Ctrl + `+` / Ctrl + `−` / Ctrl + `0` |
| Перезагрузить | Ctrl + R |
| Выход | Ctrl + Q или крестик |

Размер, положение и режим окна запоминаются между запусками.

## Как изменить содержимое

**Список проектов** — `renderer/projects.js`:

```js
window.ITD_PROJECTS = [
  { title: "CUEBOX", meta: "PRODUCT · TYPESCRIPT · PUBLIC", url: "https://example.com" },
  ...
];
```

Счётчики в ядре спирали (`17 CONNECTED SCREENS`) и в фильтре `ALL / 17`
пересчитываются автоматически. Поле `url` необязательное: если оно есть, надпись
**OPEN PROJECT** внизу становится кликабельной и открывает ссылку в системном
браузере.

**Иконка** — `scripts/make-icons.js` рисует её кодом (без графических библиотек).
После правки цветов или формы:

```powershell
npm run icons
```

**Название и версия приложения** — `package.json`: поля `productName`, `version`,
блок `build.nsis` (текст ярлыка, поведение установщика).
