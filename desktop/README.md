# I/TD Neon Spiral — приложение для Windows

Десктопная версия превью `imtrtd_neon_max_preview_v4.html`: тот же движок спирали
(колесо / перетаскивание / стрелки), без браузера, с собственным окном, иконкой,
ярлыком на рабочем столе и слоем интерфейса поверх — меню, фильтры, поиск,
палитра команд, сетка проектов.

## Что внутри

```
desktop/
├─ main.js                 окно, полный экран, снимок кадра, поверх окон, настройки
├─ preload.js              безопасный мост между окном и интерфейсом
├─ renderer/
│  ├─ index.html           разметка
│  ├─ css/base.css         спираль, карточки, нижняя панель
│  ├─ css/ui.css           меню, фильтры, сетка, панели, палитра команд
│  ├─ css/chrome.css       заголовок окна, курсор, заставка
│  ├─ js/projects.js       ← список проектов, редактируется вручную
│  ├─ js/bg.js             WebGL-фон (туманность, звёзды, реакция на движение)
│  ├─ js/audio.js          синтезированный звук без файлов
│  ├─ js/spiral.js         движок спирали
│  ├─ js/ui.js             интерфейс: фильтры, меню, поиск, сетка, панели
│  └─ js/app.js            связка с Windows: окно, горячие клавиши, настройки
├─ scripts/make-icons.js   генератор иконки (build/icon.ico, все размеры)
└─ build/icon.ico          иконка приложения / ярлыка / установщика
```

## Сборка .exe (на компьютере с Windows)

Нужен [Node.js 20+](https://nodejs.org). В PowerShell:

```powershell
cd desktop
npm install
npm run dist
```

В папке `desktop/dist` появятся два файла:

| Файл | Что это |
|---|---|
| `I-TD Neon Spiral-1.0.0-x64.exe` | установщик: ставит приложение, создаёт **ярлык на рабочем столе** и пункт в меню «Пуск» |
| `I-TD Neon Spiral-1.0.0-portable.exe` | портативная версия: один файл, запускается без установки |

Сборка не подписана сертификатом, поэтому при первом запуске Windows SmartScreen
покажет предупреждение → «Подробнее» → «Выполнить в любом случае».

### Сборка без Windows под рукой

Workflow `.github/workflows/desktop-windows.yml` собирает оба `.exe` на машине
GitHub: вкладка **Actions → Build Windows app → Run workflow**, готовые файлы
лежат в артефакте `itd-neon-spiral-windows`.

## Запуск без сборки

```powershell
cd desktop
npm install
npm start
```

## Функции

**Спираль** — колесо, перетаскивание, стрелки; активная карточка задаёт цвет всей
сцены, фон и звук подстраиваются под неё.

**Статусы проектов.** У каждого проекта есть один из трёх статусов:

- `live` — рабочий: полный неон, цветная рамка, свечение, ссылка активна;
- `paused` — на паузе: янтарная карточка, насыщенность вполовину, метка `PAUSED`
  — видно, что проект жив, но остановлен;
- `offline` — нерабочий: обесцвеченная карточка, пунктирная рамка, серая точка,
  метка `OFFLINE`; кнопка `OPEN PROJECT` заблокирована.

Приглушение действует и на активной карточке — проект на паузе или нерабочий
остаётся приглушённым, когда выходит вперёд. В фильтрах слева и в сетке для
каждого статуса есть свой пункт со счётчиком.

**Меню справа** (кнопки, наведите для подсказки):

| Кнопка | Что делает | Клавиша |
|---|---|---|
| Сетка | все проекты плиткой, клик — переход к проекту | `G` |
| Поиск | фильтр по названию, стеку, категории | `/` |
| Авто-тур | сам листает спираль, останавливается от любого действия | `T` / пробел |
| Звук | синтезированный эмбиент и щелчки переходов | `M` |
| Кадр | сохранить текущий вид в PNG | `Ctrl+S` |
| Поверх окон | закрепить окно над остальными | `P` |
| О проекте | карточка: статус, стек, доступ, ссылка | `I` |
| Клавиши | список горячих клавиш и версия | `F1` |

**Фильтры слева** — `ALL`, категории проектов и `LIVE` / `PAUSED` / `OFFLINE` со счётчиками.
В режиме сетки те же фильтры — строкой над плиткой.

**Палитра команд** — `Ctrl+K`: одним полем ищет и команды, и проекты; у нерабочих
и приостановленных стоит пометка `OFFLINE` / `PAUSED`.

Остальное: свой неоновый курсор, параллакс от мыши, часы и счётчик FPS в шапке,
заставка при запуске, уведомления в углу. Выбранный фильтр, звук, качество фона и
режим курсора сохраняются между запусками.

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Листать спираль | колесо, перетаскивание, ↑ ↓ ← → , PageUp / PageDown |
| В начало / в конец | Home / End |
| Перейти к номеру | 1 … 9 |
| Открыть проект | Enter или клик по активной карточке |
| Закрыть панель / поиск / сетку | Esc |
| Полный экран | F11 (выход — F11 или Esc) |
| Масштаб | Ctrl + `+` / Ctrl + `−` / Ctrl + `0` |
| Перезагрузить | Ctrl + R |
| Выход | Ctrl + Q |

Размер, положение и режим окна запоминаются между запусками.

## Как изменить содержимое

**Список проектов** — `renderer/js/projects.js`:

```js
window.ITD_PROJECTS = [
  { title: "CUEBOX", category: "PRODUCT", stack: "TYPESCRIPT",
    access: "PUBLIC", status: "live", url: "https://example.com",
    note: "любой комментарий для карточки" },
  ...
];
```

- `status` — `"live"` (рабочий), `"paused"` (на паузе) или `"offline"`
  (нерабочий); неизвестное значение трактуется как `offline`;
- `url` — необязателен; если он есть, `OPEN PROJECT` и Enter открывают ссылку в
  системном браузере;
- `category` — из категорий сами собираются фильтры слева;
- счётчики в ядре спирали и в фильтрах пересчитываются автоматически.

**Иконка** — `scripts/make-icons.js` рисует её кодом (без графических библиотек):

```powershell
npm run icons
```

**Название и версия** — `package.json`: поля `productName`, `version`, блок
`build.nsis` (текст ярлыка, поведение установщика).

**Производительность.** Фон рисуется шейдером в половинном разрешении. Команда
«ФОН: КАЧЕСТВО / ПРОИЗВОДИТЕЛЬНОСТЬ» в палитре (`Ctrl+K`) переключает 35 / 55 / 90 %.
Если WebGL недоступен, фон автоматически заменяется градиентами на CSS.
